# Z-Axis Awards — candidacy notes (19 Nov)

Meshy's $300K awards: https://www.meshy.ai/z-axis-awards
Free entry, deadline 24 Jan 2027, 6 tracks (Gaming fits), 70+ winners.

## Three ways we can win

- **Gaming track** (up to $10K) — a playable browser game with generated 3D
  in-scene is a real entry, not a tech demo.
- **Build-in-public rewards** ($150K pool, up to $50K) — our public repo +
  commit cadence + docs are already this.
- **Best use of Meshy** (up to $6.5K) — we prove prompt → GLB → in-game
  end to end (cloche today).

## The gap

One 70 KB cloche is a thin Meshy story. To compete for best-use we want a
visible prop pipeline: fish, pans, plate towers, cloche variants — plus the
pipeline written up (docs + devlog). ~20–30 Meshy credits, doubles as game art.
