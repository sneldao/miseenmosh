# Kitchen equipment sources

These are source assets, not yet accepted as finished in-game equipment.
Downloads used the public website through Ego; no paid generation was used.
Original source GLBs are kept unchanged.

All three Innerscene pages explicitly dedicate the original model to
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/):
“Free to use, modify and redistribute for any purpose, including commercially,
with no credit required.” Their descriptions identify unbranded original
Innerscene models. This covers the downloaded model and its included materials;
it does not license third-party reference photographs.

The tongs have separate upper/lower arms and heads, a hinge barrel and a
locking ring (6,440 triangles). The skillet has a separate body, main and
helper handles and two pour spouts. Neither needs replacement by block
geometry. The source maps need resizing and material review before use.

Reference-only photographs reviewed through the browser:

- [Serious Eats, The Ultimate Beef Wellington](https://www.seriouseats.com/the-ultimate-beef-wellington-recipe),
  recipe by J. Kenji López-Alt; searing photograph by Diana Chistruga. The
  fillet is turned with scalloped tongs in a cast-iron skillet. This reference
  supports the searing action; its foie gras/phyllo variation is not silently
  adopted as the game's recipe.
- [Serious Eats, kitchen tongs testing](https://www.seriouseats.com/the-best-kitchen-tongs-equipment-review),
  photograph by Ashlee Redger of a hand holding Cuisipro stainless tongs.
  The palm supports the channel arms, fingers wrap one arm and the thumb
  opposes it. The picture was inspected for grip and tool construction; it
  is not a game texture or a redistributable asset.
